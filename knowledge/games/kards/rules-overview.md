# KARDS rules overview

> [!warning] Version required
> KARDS is a live game. Card text, balance, formats, and mechanics can change.
> Pin a client/rules version and ingest official card data before implementation.

The rules model must represent deck construction and format restrictions, HQ and
resource state, hand/deck/discard/exile-like zones, support/front-line control,
unit movement and attacks, orders, countermeasures, triggered effects, target
selection, turn priority, victory/defeat, and deterministic effect resolution.

Card definitions belong in versioned structured data. Markdown documents mechanic
semantics and strategy; it must not duplicate every mutable card value.
